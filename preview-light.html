About me

Hi, I am Edward, a full stack developer with more than 8 years of experience building web applications for enterprise products. I like working across the whole stack: user interfaces with React, JavaScript, TypeScript and Redux, plus Angular; services and APIs with Java and Spring, plus C#; and the databases behind them. I care about clear structure, readable code, good tests and documentation that helps the next person on the team.

Lately I have been focused on how AI changes the way software gets built. I use Spec-Driven Development, agentic programming with Claude and Claude Code, reusable agent skills and prompts, and MCP, together with tools like GitHub Copilot and Codex.

What I work on

Front end and reusable UI

  • Component architecture. Atomic Design in React for a multi-facet filter panel and for the base of several dashboard instances, with Redux and Redux Toolkit for state, and UI component diagrams so the team shared the same picture. Worked with the UI/UX designer on new components.
  • Chart components. Added the base structure and styles for new chart features in a dashboard: a complex chart, a React portlet, tables and an export menu, and fixed auto-scroll and resize issues in the charts.
  • Styles and accessibility. Sass 7-1 architecture and BEM naming for component styles, plus ARIA, keyboard navigation and focus management.
  • Legacy to modern. Moved an ExtJS dashboard to React, built a React wrapper so ExtJS and Highcharts could work together, and defined a strategy to update Highcharts while ExtJS was still in use. Also worked with Angular, TypeScript with MobX, and a hybrid mobile app with Ionic.
  • Front-end testing. Jest, Jasmine, Karma and Playwright, unit-testing campaigns, and a written guide for front-end tests.

Back end and data

  • Services and APIs. Java REST APIs with Spring and Hibernate, microservices and gRPC, and SQL stored procedures on MSSQL, MySQL and ArangoDB.
  • Java migration. Defined an iterative methodology for a Java 11 migration, upgrading Spring and Hibernate by versions, and wrote migration, static analysis and dependency analysis guides, with Maven dependency management.
  • C# and .NET. Worked with C# and .NET Core, including Kafka messaging, ServiceStack, Entity Framework and Dapper.
  • Performance. Performance testing with JMeter and Datadog, and SQL optimization.
  • Python and data. Python scripts for test-result analysis and document export, and data analysis work, with data science as an area I keep learning.

AI programming

  • Agentic programming. Claude and Claude Code to plan, write and review code with AI agents, plus reusable agent skills and prompts for code review and code coverage, and a local MCP server so agents can use project information.
  • Spec-Driven Development. Requirements, specs, test cases and verification first, then code generated from approved specs with unit and integration tests, using GitHub Copilot and Codex in daily work, including AI-assisted pull request review.

Teamwork

  • Mentoring and docs. Coached teammates on Redux, React Router, Hooks and front-end unit testing, and wrote onboarding guides.

Learning
